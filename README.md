# This is Talal

Portfolio site for Talal Athar, product designer in Melbourne. Built with [Astro](https://astro.build).

```sh
npm install
npm run dev      # local dev server
npm run build    # static build into dist/
```

Pages live in `src/pages` (home, trikl, klarna, eql, contact). The About page is parked in `src/parked/about.astro`; move it back into `src/pages` to restore it.
